§1 · Closed loop

闭环总览：目标方位进，转向和开火出

整条链路只有两段是人为设定的：进入大脑前的“视觉编码”，和离开大脑后的“读出”。中间所有神经元之间的连接、突触数和兴奋/抑制符号都来自 FlyWire v783 真实数据，不做任何训练。

§2 · Runtime

两种运行方式：网页异步，Doom 锁步

同一张接线图、同一套方程，在两个宿主里的时间推进方式不同。这决定了调参时要看的指标：网页看“仿真速度是否 1× 实时”，Doom 看“每 tic 的计算耗时”。

§3 · Offline pipeline

离线数据管线：从全脑数据到网页里的 2 MB

  1. 下载原始数据FlyWire v783 连接表 Connectivity_783.parquet（1,509 万行，随 Shiu 模型仓库）+ 细胞类型标注 flywire_annotations_783.tsv（13.9 万神经元，31 MB）。
  2. 抽子图 flycircuit/extract.py突触 ≥ 5 的边上，从 LC10a 向下游、从 5 类转向 DN 向上游各走 ≤ 2 步取交集，保留内部全部连接；算出每个 LC10a 的视野位置代理和胞体坐标。输出 circuit/meta.json + circuit/edges.bin。
  3. 对照全脑 flycircuit/validate.py单眼刺激下，子图、打乱子图、13.9 万神经元 Brian2 全脑三者比较 DNa02 左右放电。
  4. 标定读出阈值 doom/fly_doom.py --calibrate把单个目标放在 −90°…+90° 共 17 个方位，测回路响应，定出 turn_th / fire_th，写入 doom/results/calibration_fly.json。
  5. 同步到网页把 circuit/* 复制到 fly-aim/data/，标定文件复制为 fly-aim/data/cal.json；flycircuit/export_brain_cloud.py 生成 3D 大脑背景点云 brain_cloud.bin。
  6. 部署静态文件 rsync 到服务器，资源带 ?v= 版本号。

§6 · Start here

如果只做四件事，先做这些

  1. 1. 修右侧偏弱

    把 THR 从 5 降到 3 重抽子图（9,201 个神经元），跑 validate.py。目标：右眼刺激时子图 DNa02 右从 4 Hz 接近全脑的 58.8 Hz。这是“子图可信度”的头号问题。

    改动：extract.py 一行；耗时：抽取几秒 + 全脑对照约 4 分钟。

  2. 2. 让结论更硬

    每组 30 局，打乱接线换 5 个不同种子，再加一组“完全随机图”（同样的神经元数和连接数）。现在“真实接线 ≫ 打乱”已经显著，但 fly 与上限、敲除 AOTU025 的结论样本还偏少。

    改动：命令行参数 + scrambled() 的种子循环；耗时：M5 上并行约 10–20 分钟。

  3. 3. Doom 改成比例转向

    现在超过阈值就整 tic 转，容易冲过头。改成“steer 越大，接下来几个 tic 里按转向键的比例越高”，和网页的比例转向一致，更贴近“DNa02 左右差决定转向角速度”。

    改动：fly_doom.py act() 加一个脉宽计数器。

  4. 4. 去掉读 AOTU019 的捷径

    给左右 DNa02 注入一个小的恒定偏置电流，让它有基线放电，这样 AOTU019 的对侧抑制能直接压低 DN，读出就可以只读 DNa02。注意不能复用现在的泊松刺激（每个脉冲 +68.75 mV 会强制放电），需要在内核里加一个单独的偏置项。

    改动：lif.py _kernel 与 lif-worker.js step() 各加一个 bias 数组；然后重标定、重跑对照。这一步做完，报告里“敲除 AOTU019 → 0 击杀部分由规则决定”的限制就可以去掉。

§8 · What else

想象空间：同一套数据和框架还能做什么

框架可复用的部分：“按细胞类型从连接组抽子图 → LIF 实时仿真 → 工程编码/读出 → 接宿主 → 打乱与敲除对照 → 神经可视化”。换一组起点和终点神经元，就是一个新项目。

不变的边界：接线图给结构，不给学习、记忆和精确的突触强度；任何新玩法都应保留打乱接线对照，才能说明“是接线在起作用”。

近期 · 用现有代码几天可做

躲避游戏逃逸回路

换起点为 LPLC2 / LC4（检测逼近物体），终点为巨纤维 DNp01。本机数据里 LPLC2 左 108 / 右 102 个、LC4 左 54 / 右 50 个，LPLC2 右 → DNp01 右 622 个突触、左侧 458 个。玩家朝果蝇扔东西，看它能不能“起飞”躲开。

可行 抽子图参数改两行，编码换成“物体逼近速度”。

雌雄对照MaleCNS

9 月发布的雄性全中枢连接组（166,691 个神经元）里同样有 LC10a 追踪通路，而它在求偶追逐中起作用。用同一套抽取与标定，比较雌雄果蝇的瞄准曲线与击杀差异。

需数据接入 neuPrint 登录取 token，或下载官方批量文件；ID 体系与 FlyWire 不同，需要重写抽取脚本的读入部分。

对战模式多只果蝇

同一场景放两只果蝇：一只真实接线、一只打乱接线（或敲除），抢同一批目标。把对照实验变成直观的比赛，适合做传播和课堂演示。

可行 开两个 Worker；每只 3,963 神经元，M5 上两只仍可实时。

课堂敲除实验室

预设任务卡：“找出让果蝇只会左转的敲除组合”“哪一个神经元对开火最关键”，学生在网页里提交答案，战绩窗自动记分。

可行 纯前端；可加分享链接保存实验条件。

中期 · 需要新模块，数周级

真正的复眼视觉

用连接组约束的果蝇视觉模型（Lappalainen 等 2024，64 种视觉细胞类型）从像素算出 LC10a 输入，替换“直接给方位角”的捷径。这是报告里第 1 条局限的正解。

中等 PyTorch 模型，Doom 离线跑可行；网页需要压缩或服务端推理。

有身体的追逐

把回路接到 NeuroMechFly（FlyGym 2.1，本机已装好并跑通走路），用 DNa02 左右差控制转向步态，让一只物理模拟的果蝇在地面上追目标。

中等 本机实测：CPU 上模拟 2 秒行走耗时 22 秒，适合录视频，不适合实时交互。

让它学会蘑菇体可塑性

加入蘑菇体 Kenyon 细胞 → MBON 的多巴胺依赖可塑性：打中“好目标”给奖励，打中“坏目标”给惩罚，看果蝇能否学会挑目标。社区 DOOMFLY 尝试过类似思路但未通过自己的验证，值得严谨地重做。

有难度 需要扩展子图到蘑菇体、实现三因子学习规则，并设计对照。

更大的网页大脑

用 WebGPU 或 WebAssembly 重写内核，把 DEPTH=3 的 48,923 个神经元搬进浏览器，3D 大脑视图里能看到更大范围的视觉脑区被点亮。

中等 边列表需改为 Uint32 目标索引；性能需实测。

远景 · 值得保持关注

实体机器人

小车或无人机用摄像头检测目标，跑同一个 3,963 神经元回路决定转向。整张图只有约 2 MB，树莓派级别的设备有望实时（需要 C 或 Rust 内核，未实测）。

探索性 可做成“用真实昆虫大脑接线控制的机器人”展示。

类脑芯片

Eon Systems 开源的果蝇大脑仓库列出了类脑芯片后端。LIF + 稀疏连接天然适合脉冲芯片，是低功耗运行的方向。

依赖硬件 目前只能关注。

可解释性对照

同一任务上并排比较“接线完全已知的果蝇回路”和训练出来的小神经网络：谁更省数据、谁更好解释、敲除一个单元时谁更鲁棒。对 AI 可解释性教学很有说服力。

可行 Doom 实验框架直接复用。

下一个物种

Janelia 正在推进带活动记录的斑马鱼幼鱼全脑连接组。框架里与物种相关的只有抽取和编码两步，数据一公开就能迁移。
