§2 · History

来龙去脉：从“有人说不可能”到“人人能玩”

果蝇只有芝麻大，却会走、会飞、会求偶、会打架、会学习。它的大脑大约 14 万个神经元，比人脑（约 860 亿）小了 60 万倍，是目前唯一“完整画得出、电脑跑得动”的复杂大脑。

  1. 2008Janelia 研究园区立项绘制果蝇大脑当时被广泛质疑“做不到也没用”。
  2. 2020“半脑”（hemibrain）连接组发布约 2.5 万个神经元，证明这条路走得通，催生了数百项研究。
  3. 2024-10FlyWire：第一张成年果蝇全脑接线图雌性果蝇，139,255 个神经元、约 5000 万个突触，发表于 Nature。同期 Shiu 等人发表“只用接线图搭出的全脑 LIF 模型”，刺激糖味神经元就能预测进食运动神经元放电。
  4. 2024数字身体就位EPFL 的 NeuroMechFly v2（FlyGym）发表于 Nature Methods：87 个关节、按 X 光显微 CT 扫描建模，能看、能闻、能在复杂地形行走。
  5. 2025Janelia × Google DeepMind 的 flybody在 MuJoCo 物理引擎里用强化学习让虚拟果蝇像真的一样走和飞，Nature 发表。
  6. 2026-03-07Eon Systems：“第一次多行为的具身大脑上传”把 Shiu 全脑模型 + 视觉模型接到 NeuroMechFly 身体上，不训练就出现觅食、梳理触角、进食。马斯克回应“哇”，全网刷屏。整合部分代码未开源。
  7. 2026-04FlyGym 2.0 重写CPU 仿真提速约 10 倍，NVIDIA GPU 提速约 300 倍——普通电脑也能流畅跑数字果蝇。
  8. 2026-09-03雄性果蝇全中枢神经系统连接组 MaleCNS v1.0Janelia、剑桥、Google Research 等在 Cell 发表：166,691 个神经元、约 1.25 亿个突触连接、11,691 种细胞类型，首次包含大脑 + 视叶 + 腹神经索，并首次对比雌雄接线差异。数据免费开放。
  9. 2026-09-07 → 10“果蝇大脑玩游戏”病毒式传播Minecraft 视频三天 24 万播放；Beat Saber 片段两天约 2200 万播放；随后 Doom、马里奥 64、侧方停车、比特币交易纷纷出现，还冒出了同名 meme 币。

中国相关：2024 年北京智源研究院团队构建了高精度仿真秀丽线虫（BAAI-WorM，Nature Computational Science）；2025 年 9 月“国际灵长类介观脑图谱联盟”在上海成立。

§3 · Concepts

四个关键词：一只数字果蝇由哪几块拼成

所有“果蝇 AI”项目都在这条流水线上做文章。看懂这四块，你就能判断任何一个新闻视频到底做了什么。

① 数据连接组

谁连着谁、连了多少个突触、是兴奋还是抑制。像一张电路板布线图，但不含“元件参数”。

② 大脑仿真LIF 神经元

把每个神经元简化成“漏水的桶”：输入攒到阈值就放电、清零。十几万个桶按布线图连起来一起跑。

③ 接口下行神经元

大脑通过约 1000 多个下行神经元指挥身体。现有项目只挑了几个：DNa01/DNa02 管转向，MN9 管进食。

④ 身体物理仿真

MuJoCo 引擎计算关节力、摩擦、足底吸附。NeuroMechFly 与 flybody 是两套开源果蝇身体。

“不训练就能动”是怎么回事

普通 AI（比如大模型）从随机参数开始，靠海量数据训练。而连接组模型的“参数”直接抄自真实大脑：在 Shiu 模型里，两个神经元之间的连接强度 = 突触数量 × 正负号（按神经递质推测）× 0.275 mV，全模型几乎只有这一个手调的自由参数。结构本身就编码了“尝到糖 → 伸口器”这类本能反射，所以通电就有反应。

它缺了什么

  • 没有学习和记忆：突触强度固定，同样的刺激永远得到同样的反应；真果蝇饿了和饱了的反应不同。
  • 神经元太简单：没有树突形状、离子通道多样性、激素调节。
  • 接口是手工挑的：Eon 自己承认，放电率怎样换算成关节力矩是“人为指定的近似”。
  • 没对照生物学验证：例如头部方向环形吸引子、中枢模式发生器等内部动态尚未核对。

一个参照：秀丽线虫只有 302 个神经元，接线图 1986 年就画完了，但至今还没有一只“完全逼真”的虚拟线虫。只有接线图，离“复制生命”还很远。

§4 · Reality check

刷屏与冷静看：流行说法 vs 实际情况

流行说法实际情况判断
“果蝇大脑被完整上传到电脑”上传的是接线图 + 极简神经元模型，不是一个“有意识的果蝇”。Eon 自己也说“上传”是个保真度光谱。Adam Marblestone 评价为“扎实的渐进一步，而非断裂式突破”。部分属实
“没用一行训练数据就会走路、进食”进食、梳理等反射确实来自接线图本身。但“走路”的步态在多数项目里由预设控制器生成，大脑只给“往哪走、多快”的信号。Fly.exe 项目直接标注“步态是工程实现的”。部分属实
“果蝇大脑学会了玩 Doom / Beat Saber / Minecraft”通常是把游戏画面喂进网络，再由另外训练的读出层或 AI 把神经活动翻译成按键；有的动作序列是过拟合录好的。三个项目都没发布“打乱接线的随机网络”对照实验，无法证明真实接线起了关键作用。严重夸大
“果蝇大脑炒比特币跑赢人类”社交媒体演示，无可复核的方法与数据；同期出现的同名 meme 币属于高风险投机。别当真
“下一步就是小鼠，然后是人脑”Eon 计划两年内做小鼠（约 7000 万神经元，是果蝇的 560 倍）。中科院徐春研究员指出难度“呈指数级增长”；严军研究员认为只有具备思想和意识才算真正的数字生命。远期愿景
“雄性果蝇全中枢图谱是连接组学里程碑”同行评审发表于 Cell，数据全部公开，首次包含腹神经索与雌雄对比。属实

判断一个新演示时，问三个问题：① 哪部分是接线图，哪部分是另外训练的？② 身体动作是大脑产生的，还是预设的？③ 有没有“打乱接线”的对照？

L1

在 Mac 上跑全脑模型：尝到糖，会不会想吃？

约 10 分钟 · 400 MB 磁盘

1. 准备工具（只需一次）

打开“终端”。需要 Homebrew，然后装 uv（一个很快的 Python 管理器，会自动下载合适的 Python 版本，不碰系统自带的 Python 3.9）。

brew install uv git

2. 下载模型与数据、建环境

# 本机已存在于 002ClaudeCodeSpace/fruitfly-lab，从零开始时才需要
mkdir -p ~/fruitfly-lab && cd ~/fruitfly-lab
git clone --depth 1 https://github.com/philshiu/Drosophila_brain_model.git
uv venv --python 3.11 Drosophila_brain_model/.venv
uv pip install --python Drosophila_brain_model/.venv/bin/python brian2 "numpy<2" "pandas<3" pyarrow joblib matplotlib ipykernel

一定要写 "numpy<2"：brian2 2.9 与最新 numpy 2.4 不兼容，会报 ndarray has no attribute 'ptp'（我实测踩到过）。

3. 运行实验 1

脚本做的事只有三行核心：列出 21 个糖味神经元的 FlyWire ID → run_exp 给它们持续 150 Hz 刺激 → 统计每个神经元的放电率。

cd ~/Documents/AISpace/002ClaudeCodeSpace/fruitfly-lab
Drosophila_brain_model/.venv/bin/python scripts/01_sugar_to_feeding.py
>>> Experiment: sugarR Excited neurons: 21 Elapsed time: 13 s 共 41,462 次放电，413 个神经元有活动（全脑约 12.7 万个） >>> MN9 放电率 = 82.3 Hz —— 大于 0：糖味信号一路传到了进食运动神经元！

怎么读结果：12.74 万个神经元里只有 413 个被点亮，说明信号走的是一条专用通路而不是“全脑沸腾”；MN9 在 82 Hz 放电，对应真实果蝇尝到糖后伸出口器。这正是 Shiu 等人 2024 年 Nature 论文的核心发现，你刚刚复现了它。

可以动手改的旋钮

  • N_RUN：试验次数，论文用 30，改大结果更稳但更慢。
  • r_poi=150 * Hz：刺激强度，试试 50 Hz，看 MN9 是否还放电。
  • 换刺激对象：在 FlyWire Codex 里搜苦味（bitter）或触角机械感受神经元，把它们的 ID 换进 SUGAR。注意 ID 属于 v630 数据版本，与 v783 不通用。

想看原版教程：用 VS Code 打开 Drosophila_brain_model/example.ipynb，内核选这个 .venv。不想装任何东西：仓库 README 里有 Colab 按钮，但官方说明 Colab 上会慢很多（约 20 分钟）。

L2

让数字果蝇身体走起来，导出视频

约 5 分钟 · 需 Python 3.12+
cd ~/Documents/AISpace/002ClaudeCodeSpace/fruitfly-lab
mkdir -p flygym-play
uv venv --python 3.12 flygym-play/.venv
uv pip install --python flygym-play/.venv/bin/python "flygym[examples]"
flygym-play/.venv/bin/python scripts/02_walking_fly.py
open output/walking_fly.mp4
果蝇在走路: 100%|██████████| 20000/20000 [00:08<00:00, 2306.86it/s] 2.0s 内胸部前进了 28.11 mm；视频已保存：.../output/walking_fly.mp4

发生了什么：物理步长 0.1 ms，2 秒共 20,000 步。6 个耦合振荡器（CPG，每条腿一个）产生“三足步态”——左前、右中、左后三条腿一组交替着地，这是昆虫最经典的走法。注意：这里没有接大脑，步态是预编程的，这也正是许多“大脑驱动走路”演示的底层做法。

  • Mac 上不要装 flygym[warp]，那是 NVIDIA GPU 加速专用。
  • 改 RUN_TIME 走更久；改 coupling_strength（耦合强度）看步态会不会乱。
  • 下一步推荐官方教程：flygym-src/tutorials/4d_turning_controller.ipynb（转向）和 1a_basic_model_composition.ipynb（自己拼身体和场景）。
L3

像神经科学家一样做“敲除实验”

约 2 分钟 · 复用 L1 环境

真实实验室会用遗传工具让某个神经元“闭嘴”，看行为是否消失。在数字大脑里只要把它所有输出突触的权重设为 0。脚本自动挑出糖味神经元之外最活跃的 3 个中间神经元，逐个静默，再三个一起静默，比较 MN9 的放电率：

Drosophila_brain_model/.venv/bin/python scripts/04_silence_neuron.py

再往上：把大脑和身体接起来

这是 Eon 做的事，也是目前最前沿、门槛最高的部分。先说清楚现状：

项目做了什么硬件Mac 能跑吗
eonsystemspbc/fly-brainEon 开源的全脑模型多后端版本（Brian2、PyTorch、GeNN 等），用于速度对比；不含身体整合Linux + NVIDIA CUDA 12未测试
erojasoficial-byte/fly-brain社区版：v783 全脑 + NeuroMechFly 身体，约 1100 个下行神经元转成关节力矩，含视觉/嗅觉/飞行NVIDIA ≥ 6 GB 显存，32 GB 内存不支持
Fly.exeMaleCNS 16.5 万神经元闭环驱动 12 只果蝇；诚实标注“步态是工程实现、无社会行为”NVIDIA（RTX 3060 实测）不支持

Mac 用户的自制思路：把 L1 和 L2 串起来。每 15 ms 让大脑跑一小段，读出 MN9 放电率决定“要不要进食”，读出 DNa01/DNa02 的左右差值决定转向，喂给 L2 的转向控制器。这正是 Eon 公开描述的同步方式，适合作为你的第一个小项目。

  6. 首次运行实验 1 报错

    原因：uv 默认装了最新 numpy 2.4.6，它删除了 ndarray.ptp，而 brian2 2.9.0 仍在调用。修法：uv pip install "numpy<2" "pandas<3"。

    41,462 次放电、413 个活跃神经元、MN9 = 82.3 Hz。第二次起快了 5 倍，因为 Brian2 首次运行时要把模型编译成 C++（Cython）并缓存。

  9. 运行实验 2：数字果蝇走路 总计 22 s 成功

    20,000 个物理步，约 2,400 步/秒，不到 CPU 上的实时速度。默认视频只有 320×240、0.2 倍速，偏小；改为 camera_res=(480, 640)、playback_speed=0.25 后重新渲染，得到 8 秒、4.4 MB 的清晰视频（标本板 A）。抽帧检查画面正常：红色复眼、翅膀、六足着地、地面倒影。

  10. 导出放电栅格数据 完成

    03_export_raster.py 取第 1 次试验中最活跃的 40 个神经元（强制包含 MN9），导出 38 KB 的 JSON，嵌入本页绘制标本板 B。图表配色经色盲安全校验脚本检查，浅色与深色主题均通过。

  11. 运行实验 4：敲除 成功

    逐个静默 3 个最活跃中间神经元，再三个一起静默。控制台出现 Brian2 警告 'i' is an internal variable of group 'default_synapses'，是官方 silence() 函数里循环变量与内部变量同名所致，内部变量优先，结果正确，可忽略。结果见 L3。

  12. 未实测的部分 说明

    脑身整合的社区项目（erojasoficial-byte/fly-brain、Fly.exe、Eon 多后端版）都依赖 NVIDIA CUDA，本机无法运行，未测试；MaleCNS 的 neuPrint API 需要登录取 token，未代为登录。

§7 · FAQ

常见问题

我完全不会编程，能玩吗？
能。L0 全部在浏览器里完成。L1、L2 只需复制粘贴命令，脚本已写好，每行都有中文注释。
会不会弄乱我的电脑？
不会。所有依赖装在项目文件夹里的 .venv 中，删掉 fruitfly-lab 文件夹就彻底清除。
Windows 或没有 Mac 怎么办？
命令基本相同（路径把 .venv/bin/python 换成 .venv\Scripts\python）。也可以用 Colab：全脑模型仓库和 FlyGym 教程都提供 Colab 入口。
这个数字果蝇有意识吗？会痛吗？
没有证据表明有。它是固定权重的简化电路，没有学习、记忆、内部状态。围绕“数字生命”的伦理讨论值得关注，但与今天能跑的模型距离很远。
这对 AI 有什么用？
三个方向：用生物接线当神经网络结构（样本效率更高，2026 年有论文用全脑图当强化学习控制器）；用数字身体设计机器人；在电脑里先做“敲除实验”，筛选值得在真果蝇上验证的假设，省实验成本。
看到“果蝇大脑炒币”的币要不要买？
不要把它当投资机会。它和科研成果没有关系，属于高风险投机。
